Kalau maksudmu edit website KStudio yang sudah kamu upload ke GitHub, gampang kok 😭💜

💻 Cara edit langsung di GitHub

  1. Buka GitHub dan login.

  2. Masuk ke repository KStudio kamu.

  3. Cari file:

    • index.html → isi/struktur website

    • style.css → warna, ukuran, layout, font, dll.

    • script.js → animasi dan fungsi/interaksi

  4. Klik file yang mau diedit.

  5. Klik ikon ✏️ Edit this file di kanan atas.

  6. Ubah kodenya.

  7. Scroll ke bagian bawah.

  8. Klik Commit changes.

🎨 Kalau mau mengubah tampilan

Misalnya mau ganti warna KStudio, buka style.css, lalu cari:

CSS
:root {
  --floral-white: #fffaf2;
  --lavender: #e7d9f5;
  --periwinkle: #aeb8ee;
  --wisteria: #9b8bc7;
  --pearl-aqua: #a9ded7;
}

Kamu tinggal mengubah kode warnanya.

⚠️ Kalau website kamu pakai GitHub Pages

Setelah Commit changes, GitHub Pages biasanya akan memperbarui website secara otomatis setelah beberapa saat.

Kalau kamu mau, kirim link repository GitHub KStudio kamu. Aku bisa kasih tahu file mana yang harus kamu klik dan bagian mana yang harus diedit, langkah demi langkah.
