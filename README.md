# KSTUDIO Cute Pink Edition
Modern cute music landing page, responsive and ready for GitHub Pages.

## Brand colors
Soft Blush #F7D6D0
Pastel Pink #F4C2C2
Baby Pink #F8D7E3
Bubblegum Tint #F6A6C1
Bubblegum Pink #E88BAA

## Files
index.html
style.css
script.js

Upload all three files to the root of a GitHub repository and enable GitHub Pages from Settings → Pages → Deploy from branch → main → root.
