# KSTUDIO Music Website

Modern responsive music streaming-style UI, ready for GitHub Pages.

## Files
- index.html
- style.css
- script.js

## GitHub Pages
Upload all three files to the root of a GitHub repository, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Notes
The visual uses remote Unsplash images with `auto=format` and `q` parameters so the images can load directly without storing large assets in the repository. The Play button is a UI demo and does not contain copyrighted audio.
